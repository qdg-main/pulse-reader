The runtime end-user licence is not, by itself, a publisher redistribution
grant. Publisher entitlement comes from the supplying Visual Studio edition
and the Distributable Code list. The Community terms permit individual
developers' own applications and qualifying open-source projects, with
conditions. Those conditions include significant primary functionality and
end-user/distributor terms protecting the Microsoft Distributable Code at
least as much as Microsoft's agreement. They do not relicense Pulse Reader's
MIT source or unrelated open-source components as proprietary software.

The exact documents are preserved alongside a scoped package agreement.
Distribution-Terms.txt combines Pulse Reader's MIT licence, the complete original
runtime text and a separate introduction limited to these four Microsoft files.
The installer presents it; portable launch requires agreement before application
setup or speech. An accepted content hash is recorded for the Windows user.
Changed terms require fresh acceptance. Silent installation requires explicit
/ACCEPTDISTRIBUTIONTERMS=yes after reviewing that text.
